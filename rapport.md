Vilken är din valda metod och teknik för källkodshantering?

Jag har valt att använda mig av Git och Github och för att göra arbetet ännu smidigare använder jag mig av Github Desktop som i min mening gör det enklare att köra puch, pull och commit.



Förklara och motivera hur du har valt att arbeta med din källkod under den fortsatta kursen. Var tydlig med att motivera valet av både teknik (git) och metod (hur du tänkt arbeta).


Genom att kombinera Git och GitHUb med GitHub Desktop blir det enkelt att pusha, pulla och mergea ändringar på ett strukturerat sätt som gör arbetet säkrare och mer organiserat. jag tänker använda mig av regelbundna commits så att jag enkelt kan gå tillbaka om något skulle gå fel och inte förlora så mycket arbete på vägen. Jag kommer också arbeta med olika brancher där varje branch representerar en del av projektet. Till exempel om jag gör startsidan kommer branchen heta något i stil med StartBranch. Enkla namn som beskriver vad branchen innehåller. När en branch är klar pushar jag upp den och mergar mot main branchen, eller pushar upp tidigare beroende på hur stor delen som arbetas med är.
